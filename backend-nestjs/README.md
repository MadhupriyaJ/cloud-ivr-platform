# Generic IVR Platform Backend

This is a NestJS scaffold for a generic multi-domain realtime IVR platform.

## Setup

1. Copy `.env.example` to `.env`
2. Update MSSQL and Azure credentials
3. Install dependencies
4. Create an empty database, then run `npm run db:migrate:all` (all schema + seed files, in order)
5. Start backend

## Commands

```bash
npm install
npm run start:dev
```
